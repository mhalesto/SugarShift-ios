# Engine implementation brief

Work only on Engine.swift, new pure Swift model/engine files, LevelBoardFactory.swift, LevelSimulation.swift, TurnStrategy.swift, and new SugarShiftTests/EngineRedesignTests.swift. Main owns GameScene*, Levels.swift, level/objective/theme catalog and UI. Do not modify localization, persistence, git history, or project settings. No subagents. Coordinate interfaces promptly. Main builds; use same derived path only when main confirms build slot.

Preserve Engine/Grid/Cell APIs used by mature scene and existing tests. Add typed PieceColor seven cases (orange/grape/blueberry/leaf/banana/heart/strawberry), mapping legacy palette in that order; eighth mango can map orange without changing old tokens. Piece identity independent of art. Introduce Piece and BoardTile structs; a Cell is a slot with a Piece plus fixed tile/blocker metadata. Computed id/color/special/kind compatibility is permitted. Keep blocker/tile fixed during swaps/gravity/conveyors, and split gravity at immovable blockers. No fruit can swap through honey/cage/lock/stone. Underlying jelly stays at its grid location and loses a layer when its fruit clears. Existing simple ice/lock absorbing damage can stay compatible where possible.

Extend BlockerType and configuration-driven rules for honey, stone, cage, licorice, solid X, cream, bubble, magicFrost, donut. Support hits, layer, canContainPiece, canFall, blocksMovement, blocksBlast, spreads, destructionRules and optional required keys. Avoid scattering case switches outside model policy. clearMatches accepts default normal damage plus optional special/combo/hammer context. Normal adjacent damage affects configured obstacles; magic frost special-only; indestructible blocks survive. Line blasts stop at configured licorice/solid walls.

Keep old six specials working and add lineBlast, rocket, ufo. All unordered pairings resolve deterministically (45 pairs); add a generic advanced pair kind if appropriate. Striped+striped always one row+column; wrapped single activation is 3×3 with second-stage descriptor, wrapped pair radius2 staged; Color Bomb conversion footprints and fish objective targets chain all specials exactly once. Add pure staged activation descriptors consumed by main (report API). Cross formation lineBlast only where formation truly has four arms; T/L remains wrapped. Square fish.

Gravity: existing collapseAndRefill gains optional portals and spawnWeights arguments (default legacy behavior). Transfers source to empty portal exit during gravity before spawning, never swaps two occupied portal cells. Bounded loops and looped/invalid portal validation. Conveyors move once per completed player turn (main changes scene); pure function preserves anchored metadata and blocked occupants. Simulator must follow same ordering. Add canonical bounded Engine.shuffledPlayableGrid that preserves pieces/specials/blockers/shape and returns optional valid board with no initial runs/squares and at least one move. Do not silently return invalid boards.

Write meaningful regressions first around old behaviors that are wrong, run/fail before implementation, then implement and verify. Existing tests intentionally specifying obsolete behavior may be updated with rationale. Report exact files/interfaces/tests and gaps. Core logic contains no SpriteKit. No new disconnected engine: all changes must serve existing scene/simulation.
